# 板端 Python 应用

生产源码位于 `src/ec_26_e/`，配置位于 `configs/`。本目录使用 Poetry 管理依赖，通过 `puzzle_solver` 公共 API 调用几何求解器。

## 安装与测试

在本目录执行 `poetry install`。内部依赖来自 `../../data/dependencies/` 中的固定 wheel，公共依赖版本由 `poetry.lock` 锁定。

软件测试位于 `../../sim/tests/`。在仓库根运行 `./sim/run_tests.ps1 -All` 执行主机适用测试；`-Full -All` 运行完整单元与集成集合。设备测试需在相应硬件环境中单独执行。

## 板端配置

启动脚本和配置模板位于 `../../board/runtime/`。默认采用 CPU、仅规划模式，关闭运动与实体按键。程序入口包括 `ec-26-e` 和兼容命令 `ec-7020`。

## 运行计时

计算时间从点击运行开始，截止到完整方案交给运动执行器之前；总时间截止到执行器返回和任务收尾。任务结束后保持两个数值，下次运行重新计时。仅规划、取消和失败显示各自的结束状态，日志标记为 `TASK_TIMING`。

完整构建步骤见仓库根目录的 [工程说明](../../README.md)。
