# 报告与工程技术资料

本目录用于归档正式设计报告及配套技术资料。当前未包含正式设计报告的 Word、PDF 文件；工程说明不能替代正式设计报告。定稿后，设计报告直接放在本目录。

| 位置 | 内容与用途 |
|---|---|
| `engineering/` | 架构、算法、接口、菜单、PL 加速、运动桥接及部署说明，供理解工程、复现和编写报告参考 |
| `provenance/` | 文件来源及整理映射，用于追溯源文件与交付副本 |
| `collaboration/` | 大模型协作原始记录及索引的归档位置，当前原始记录待补充 |
| `submission_notes.md` | 提交材料清单与待完成项 |

## 构建与实测资料位置

- 综合、实现、时序、资源和 HLS 参考报告：`../build/reports/reference/`。
- 当前源码、软件测试、仿真和工程检查结果：`../build/reports/current/`。
- 仿真和验证入口、测试平台及输入：`../sim/`，结果索引见 `../sim/readme.md`。
- 上板实测输出和带日期的验证记录：`../board/results/historical/`。

各类结果保留原有版本、平台、输入与计时范围；软件测试、规划成功和实物运动验收分别记录。
