# FPGA 工程开发技能

本技能提供 RTL/HLS、IP 集成、时序约束、SoC 软件适配和分阶段验证的工作流程。

## 使用

阅读 [技能定义](SKILL.md)，按任务选择 [工程组织](references/project-layout.md) 或 [构建与验证](references/build-validation.md)。执行前准备具体器件、板卡资料、工具版本和工程入口。

在支持技能调用的开发工具中，可将本目录安装为 `xilinx-fpga`。目录包含技能定义、参考资料和 `agents/openai.yaml` 工具配置。

## 验证范围

工程检查分别记录源码引用、仿真、综合、实现、硬件文件导出和上板结果。模块仿真用于确认接口行为，完整实现用于检查资源与时序，目标硬件测试用于确认外设和实际性能。
